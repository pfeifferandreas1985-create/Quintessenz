# doomsdaybox/ — Beschaffungspaket der Wissensbox (Spiegel aus D:\DoomsdayBox)

Hier liegen **nur die Unterlagen und Werkzeuge**, nicht die Daten: Spezifikation, Wissensübersicht,
Übergabe an den Download-Agenten, Logbuch, Bericht Phase F, alle Skripte (`tools/`), die
Abhängigkeitsbäume (`own/rebuild`), Fahrzeugakten mit Datenbank und Teilelisten (`own/fahrzeuge`)
und die Hochspannungs-Pipeline (`own/hvkb`). ZIM-Archive, PDFs, Karten und Modelle bleiben auf D:
(siehe `.gitignore`) — Umfang und Prüfsummen stehen im `LOGBUCH.md`.

Maßgeblich ist immer D:\DoomsdayBox; dieser Ordner wird nach Änderungen von dort kopiert.
